# 📚 askpc.cc — Community Documentation Vault

Welcome to the open documentation repository for [askpc.cc](https://askpc.cc)!

Anyone can write, fix, or improve technical documentation here. Once your Pull Request is merged into `main`, it will automatically sync to [askpc.cc/kb](https://askpc.cc/kb).

---

## 🚀 How to Contribute

1. **Fork** this repository.
2. Create a new `.md` file inside the `docs/` directory.
3. Add mandatory YAML Frontmatter at the top of your `.md` file (see template below).
4. Write your article using standard Markdown or Obsidian syntax.
5. Open a **Pull Request** to `main`.

---
